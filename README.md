# Premia

Construa um aplicativo mobile de sorteios de produtos, esses sorteios acontecerão semanalmente, cada produto será exibido em um tipo de banner e abaixo de cada banner deverá ter o botão Adicionar no Carrinho, o usuário ao parar naquele produto, deverá clicar no botão "Adicionar no Carrinho", logo o app irá gerar um número da sorte equivalente a 5 dezenas aleatórias referente aquele produto escolhido. Após ter escolhido seus itens que irão ser sorteados, o usuário deverá ir para o painel de pagamento onde ele poderá pagar via PIX ou Cartão de Crédito ou Débito. Por enquanto esse é a ideia inicial do projeto, vamos construir esse projeto ousado? Depois a gente pensa em um nome impactante para o app.
